# Security

Applies to every repo in [somos-criptonautas](https://github.com/somos-criptonautas).

## Reporting a vulnerability

Do not open a public issue. Use **Security → Report a vulnerability** on the
affected repo, or write to dev@criptonautas.co.

Include the repo, the commit or version, what an attacker can do, and how to
reproduce it. We answer as soon as we can and credit you in the fix unless you
prefer otherwise.

If the bug is in code inherited by a fork, please report it to the original
project too. The parent is linked in the fork's README.

## What is supported

Only the `main` branch of each active repo. Archived repos get no fixes.

Please test against your own install, never against our live sites.
